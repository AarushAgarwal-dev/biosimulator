BioSimulateAI: An AI-Powered Platform for Automated Multi-Scale Biological Model Generation, Simulation, and Calibration
Aarush Agarwal, L. Li
Purdue University
Abstract

Mathematical modeling of biological systems has traditionally been a highly manual and error-prone process requiring deep expertise in both biology and applied mathematics. We present BioSimulateAI, an integrated web platform that automates the translation of natural-language descriptions of biological systems into executable, multi-scale mathematical models. The system combines Retrieval-Augmented Generation (RAG) from curated biological knowledge bases (Reactome, STRING, OmniPath, SIGNOR, BioModels) with Large Language Model (LLM) compilation to produce structured simulation blueprints. These blueprints drive three tightly coupled simulation engines: (i) a symbolic Ordinary Differential Equation (ODE) compiler using Hill-function kinetics with SymPy-based code generation, (ii) a finite-difference Partial Differential Equation (PDE) solver for reaction-diffusion systems, and (iii) a Cellular Potts Model (CPM) for spatial, agent-based tissue simulations.

To ensure physical and biological accuracy, the platform features a strict validation layer that preemptively rejects impossible conditions, such as mass conservation violations. A closed-loop AI feedback agent evaluates simulation outcomes against user-defined experimental targets, iteratively refining model parameters and topology. Additionally, we implement structured parameter extraction from scientific literature using hallucination-detection validators to ground the models in published empirical data. BioSimulateAI is accessible through a browser-based interface requiring no local installation and operates with or without an LLM API key via robust rule-based fallback parsers, accelerating the iterative cycle of hypothesis testing and model validation in systems biology.

Keywords: systems biology, multi-scale simulation, retrieval-augmented generation (RAG), large language models, cellular Potts model, mathematical modeling, automated calibration
